# Prototype Project

A small static web page prototype presenting basic information about **Kaplan Business School**.

## Contents

| File | Description |
| --- | --- |
| `index.html` | Single-page, self-contained site (HTML + inline CSS, no dependencies) |
| `dashboard.html` | Colourful student dashboard (sample data): sortable-looking table, search/filters, click-through profiles with skills charts, 5 themes |
| `README.md` | Project documentation (this file) |

## Getting started

No build step or installation is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/kisshan2202/prototype_project.git
   cd prototype_project
   ```
2. Open `index.html` in any modern web browser, or serve it locally:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit <http://localhost:8000>.

## About the page

`index.html` is a responsive page with an overview of Kaplan Business School, the kinds of study options it offers, its key features, and a link to the official website. It is intended as a simple prototype, not an official school page.

> **Note:** The content is a general summary written for demonstration purposes. For current courses, fees, campuses and admissions, always refer to the official website: <https://www.kbs.edu.au>.
